# zella-peakegt-notes

Machine Learning · Distributed Systems · Terraform

学习用的示例项目

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/zella-peakegt-notes.git
cd zella-peakegt-notes
cargo build --release
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。
